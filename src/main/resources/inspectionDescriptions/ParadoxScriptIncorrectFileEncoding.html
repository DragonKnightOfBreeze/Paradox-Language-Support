Reports script files with incorrect file encoding.

In detail, it should be UTF-8 NO BOM.

In particular:

  • For Stellaris, it should be UTF-8 BOM for script files under directory common/name_lists (before 4.6), otherwise UTF-8 NO BOM.
  • For other game types, whether to use a BOM depends on the game type and the file path; this inspection does not verify these cases at the moment.

Description:

  • Ignore injected files and temporary files.
  • Ignore empty files additionally.
