Reports unresolved expressions in CSV files.

If the current node has corresponding row config and column config, but the column config does not match, the check is considered failed.

This code inspection is directly skipped when certain special cases are involved. For example: it is ignored because a matching extension config exists.

NOTE: This code inspection is based on config files, so if it produces false positives, it usually indicates that the config files for current game type is incomplete. Consider disabling or suppressing this code inspection if needed, or contributing configs.
