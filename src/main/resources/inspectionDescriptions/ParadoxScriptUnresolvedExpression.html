Reports unresolved expressions in script files.

If a config context exists for the current node, but no matched configs are found, the check is considered failed.

This code inspection is directly skipped when certain special cases are involved. For example: when its config context specifies to skip the check, or when it is ignored because a matched extension config exists.

If the current node fails the check and the parent node also fails the check, this code check is skipped to avoid redundant error reporting. For example: if a property key cannot be resolved, then the property value will not be further checked. If a block cannot be resolved, then its members will not be further checked.

NOTE: This code inspection is based on config files, so if it produces false positives, it usually indicates that the config files for current game type is incomplete. Consider disabling or suppressing this code inspection if needed, or contributing configs.
