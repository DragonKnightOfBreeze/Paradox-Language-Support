# 领域名词与术语表

> 本文档规范 Paradox Chronicle 插件及维护者笔记中所使用的领域专有名词对照与标准中文翻译。

## 名词对照

### 通用核心术语

| 英文原词 (English) | 推荐中文翻译 (Chinese) | 补充说明 |
| :--- | :--- | :--- |
| **scope** | **作用域** | 模组脚本中的上下文与“主语” |
| **modifier** | **修正** | 对游戏数值的加成/减损属性 |
| **trigger** | **触发器** | 模组脚本中的条件判定谓语 |
| **effect** | **效果** | 模组脚本中的执行操作谓语 |
| **scripted variable** | **封装变量** | 脚本中通过 `@var = 1` 声明的变量 |
| **localisation** | **本地化** | 多语言文本资源（YAML） |
| **define** | **定值** | 游戏引擎基础参数定值 |
| **definition** | **定义** | 模组中的数据对象声明（事件、特质等） |
| **scripted trigger** | **封装触发器** | 可复用的触发器宏组合 |
| **scripted effect** | **封装效果** | 可复用的效果宏组合 |
| **script value** | **脚本值** | 可计算的数值公式定义 |
| **game rule** | **游戏规则** | 游戏内核行为规则定义 |
| **on action** | **动作触发** | 游戏事件分发驱动点 |
| **event** | **事件** | 游戏内弹出的交互或后台事件 |
| **event namespace** | **事件命名空间** | 事件标识符前缀命名空间 |
| **sprite** | **精灵** | 界面贴图与图形元素 |
| **macro** | **宏** | 语法/语义级别的代码复用结构 |
| **inline script** | **内联脚本** | Stellaris 等游戏中的脚本文件内联宏 |
| **definition injection** | **定义注入** | VIC3 / EU5 等游戏中的定义注入宏 |
| **config** (CWT) | **规则** | CWT 规则文件体系中的规则声明 |
| **config group** | **规则分组** | 绑定到特定游戏类型的规则集合 |
