# 脚本片段注入机制设计 (Script Injection)

> 注：本文档记录历史性的设计与实现思路，以后可以考虑进一步补充与完善。

## 概述

提供数种方式，可以为注入的脚本片段提供 CWT 规则上下文，以便后续提供高级语言功能。

## 注入场景

注入的脚本片段包括以下几种情况：

- 手动语言注入
- Markdown 文件中 code fence 的语言注入
- 对于脚本文件中作为参数值的用引号括起的参数值，强制进行语言注入（注入脚本片段）

## 高级语言功能支持

基于 CWT 规则，为注入片段提供如下功能：

- 基于 CWT 规则提供文件高亮
- 基于 CWT 规则提供引用解析、代码导航、快速文档等功能
- 基于 CWT 规则提供代码补全

## 规则上下文分类

- 直接的规则上下文
- 内联脚本调用中的规则上下文
- 内联脚本文件中的规则上下文
- 来自脚本参数值位置的规则上下文
- 来自手动语言注入的规则上下文

## 实现方式

- **简单脚本片段**：手动实现，直接解析。
- **复杂脚本片段**：通过语言注入功能（注意：IDEA 不支持嵌套的语言注入）。
