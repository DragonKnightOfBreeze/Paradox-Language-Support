### 委托到 Kotlin 属性

```
// byKotlinProperty
// Kotlin: top-level, class

var $name$: $type$ // region by $delegateClassC$::$delegateC$
    get() = $delegateClass$.$delegate$
    set(value) = run { $delegateClass$.$delegate$ = value } // endregion
```

### 访问 `MetadataMap` 中的元数据

```
// byMetadata
// Kotlin: top-level, class
 
var $name$: $type$ // region by $keysC$.$keyC$
    get() = this[$keys$.$key$]
    set(value) = run { this[$keys$.$key$] = value } // endregion
```

## 正则

### 规范化注释

```
(^\s*//)(\S)
$1 $2
```

```
(\s+//)(\S)
$1 $2
```

### 将 `key = {...}` 替换为 `key`

```
^\s*(\w+)\s+=\s*\{([\s\S]*?\n\}|[ ]*\})
$1
```

### 为 `CHANGELOG.md` 中的独立 Issue ID 批量替换为链接

```
(?<=\s)#(\d+)(?=\s|$)
[#${1}](https://github.com/DragonKnightOfBreeze/Paradox-Language-Support/issues/${1})
```

说明：

- 通过前向与后向断言限制匹配范围，避免误伤标题中的 `##` 或普通文本中的 `abc#123`。
- 末尾允许行尾结束，从而兼容列表项尾部的 `#123`

### 将委托属性替换为显式属性

替换为不可变可变属性：

```
override val (\w+): (.*) by Keys.(\w+)

override val $1: $2 // region
    get() = this[Keys.$3] // endregion
```

替换为可变属性：

```
override var (\w+): (.*) by Keys.(\w+)

override var $1: $2 // region
    get() = this[Keys.$3]
    set(value) = run { this[Keys.$3] = value } // endregion
```

参见：
- `icu.windea.pls.config.configGroup.CwtConfigGroupDataHolderBase`
- `icu.windea.pls.config.option.CwtOptionMetadataBase`
- `icu.windea.pls.config.configExpression.CwtDataExpressionMetadataBase`

## PowerShell 命令

### 建立指向共享的 AI 规则目录（`documents/ai-rules`）的目录联结

```powershell
$ErrorActionPreference = 'Stop'
$ts = Get-Date -Format 'yyyyMMdd_HHmmss'

# 1. Backup existing .windsurf\rules (rename only the leaf name)
if (Test-Path '.windsurf\rules') {
  Rename-Item -Path '.windsurf\rules' -NewName ("rules.bak_{0}" -f $ts)
}

# 2. Backup existing .clinerules (rename only the leaf name)
if (Test-Path '.clinerules') {
  Rename-Item -Path '.clinerules' -NewName (".clinerules.bak_{0}" -f $ts)
}

# 3. Validate target exists
if (-not (Test-Path 'documents\ai-rules')) { throw "Target 'documents\\ai-rules' does not exist." }
# 4) Create junctions
New-Item -ItemType Junction -Path '.windsurf\rules' -Target 'documents\ai-rules' | Out-Null # windsurf
New-Item -ItemType Junction -Path '.clinerules' -Target 'documents\ai-rules' | Out-Null # cline
Write-Host 'Junctions created'
```

备注：似乎 windsurf 的规则文件必须不能被 `gitignore` 忽略，并且也不能使用目录联结，否则重启项目后可能会出现问题，导致无法被识别……

### 查询一组版本标签对应的发布日期

```powershell
$tags = 'v2.0.0','v2.0.1'
foreach($t in $tags){
  $d = git log -1 --format=%as $t
  Write-Output "$t|$d"
}
```

说明：

- `git log -1 --format=%as <tag>` 适合快速取出标签所指向提交的日期，便于补到 changelog 的版本标题中。
- 如果仓库里同时存在 `v2.0.0` 与 `2.0.1` 两种风格的标签名，可以优先查前者，再回退到后者。
