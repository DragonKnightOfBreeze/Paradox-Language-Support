# 支持匹配带前缀标签的脚本表达式

> 所属模块：`后端 > 规则系统`
> 上级导航：[架构决策索引 (ADR Index)](README.md)

> - 版本：v3.2.0+
> - 日期：2026-07-14+
> - 状态：TODO
> - 相关问题：https://github.com/DragonKnightOfBreeze/Paradox-Language-Support/issues/263

"前缀标签"指目标脚本表达式之前紧邻的作为前缀的字符串，例如 `k = list v` 中的 `list`。

说明：
- 将这个需要前置的字符串（无论是直接的值，还是属性值）视为特殊标签，拥有类似注解的高亮和图标。
- 考虑通过选项 `## prefix_tag` 来标记这种特殊的标签（`## tag` 目前已经用来标记单独的特殊标签，仅适用于直接的值，典型例子是 `optimize_memory`）
- 可能的解决方案是同时在成员规则的兄弟节点，以及脚本成员的兄弟节点之间进行绑定与检测。
- 将标有这个选项的成员规则的下一个兄弟节点作为紧随其后的脚本成员需要匹配的规则。
