计划：
- [x] 为了同时兼容 `a_[command]_b` 和 `a_[PARAM[text]]_b`，需要考虑引入对应的尾随上下文。
- [x] 进入条件化块/内联条件化块后，应根据当前上下文堆栈，决定需要切换到的上下文（state+expect）。
- [x] 扫描时默认不区分条件化块的形式（普通/内联），但是优先视为内联形式，并在必要时回退到普通形式。
- [x] `key = [text]` 和 `key = "[text]"` 中的 `[text]` 应被视为普通字面量（在语义上可能表示一个本地化命令）。
- [x] 脚本文件中的 `]` 仅当在以 `[` （`LEFT_BRACKET`）开始的语法中，才被视为 `RIGHT_BRACKET`，否则应根据上下文，回退为普通的字面量或标识符。
- [x] 对于 `"[ [ PARAM ] text ]"`，需要将其中的条件化块识别为内联形式。并且，除了 ` text ` 需要被识别为 `STRING_TOKEN` 之外，其他的空白需要被正常识别为 `WHITE_SPACE`。
- [x] 对于 `[[A] k=v]`，由于其中的空白词元，可以正常识别为普通形式。
- [x] 对于 `[[A]k=v]`，尽管其中没有任何空白词元，也需要识别普通形式。因此，这意味着在遇到分隔符（而此时条件化块未正常结束）时，也需要按需回退并更改上下文。
