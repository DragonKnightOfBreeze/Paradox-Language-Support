对于本地化文件中的特殊语法（高级富文本），需要研究在不同游戏中的支持情况，从而进行相关的重构和优化。

本地化文件的本地化文本中存在以下几种基本富文本语法（目前插件认为所有游戏都支持，尽管这实际取决于游戏引擎的底层实现）：
- **文本（text）**：没有任何特殊格式的纯文本。
- **参数（parameter）**：如 `$PARAM$` 或 `$PARAM|ARG$`。这可以引用一个本地化条目或一个预定义的参数/变量。其中也可以引用封装变量，如 `$@var$`。
- **命令（command）**：如 `[Root.GetName]`。

本地化文件的本地化文本中存在以下几种高级富文本语法（不同游戏的支持情况可能不同）：
- **彩色文本（colorfulText）**：如 `§Rtext§!`。`R` 对应一个文本颜色（即类型为 `text_color` 的定义）。这不一定被所有主要游戏类型支持，需要研究。
- **图标（icon）**：如 `£name£` 或 `£name|arg£`。`name` 存在数种解析策略，不同文件之间也可能存在区别。这不一定被所有主要游戏类型支持，需要研究。据说有些游戏类型（比如 Hoi4）不要求作为后缀的 `£`。
- **概念命令（conceptCommand）**：如 `['concept']` 或 `['concept', text]`。`concept` 对应一个游戏概念（即类型为 `game_concept` 的定义）或者一个 databaseObjectExpression。这应当仅被 Stellaris 支持。
- **文本格式（textFormat）**：如 `#name text#!`。`name` 对应一个文本格式（即类型为 `text_format` 的定义，忽略大小写）或者预定义格式/内联格式（类似 HTML 中的 style 属性值）。这应当仅被基于 Jomini 的游戏类型支持。
- **文本图标（textIcon）**：如 `@name!`。`name` 对应一个文本图标（即类型为 `text_icon` 的定义）。这应当仅被基于 Jomini 的游戏类型支持。

插件目前尚不能很好地支持 **文本格式** 和 **文本图标**。需要在未来继续完善……
