# 宏展开与求值支持

> - 模块：后端 > 语言功能支持
> - 版本：v3.2.0+
> - 状态：待规划（拆分自原 `roadmap.md`）
> - 标签：`里程碑` / `语言功能` / `Macro` / `InlineScript` / `ScriptValue`

## 概述

宏展开与求值的完整支持体系，涵盖展开/求值器引擎、对应的意向动作（Intention）、预览交互 UI 与诊断提示。

## 候选任务

- [ ] P3/MAYBE 实现 `script_value` 的评估器，提供对应的求值意向动作（若依赖游戏运行时上下文，则展示为动态结果或条件结果）
- [ ] P3 实现内联脚本（`inline_script`）的展开评估器，提供对应的意向动作（单步展开 / 递归展开）：
  - 点击打开非阻塞的预览界面，支持复制文本及打开为临时文件；
  - 保留展开后仍然带参数的用法；
  - 忽略存在递归引用的用法，并给出警告注释。
- [ ] P3 实现 `scripted_trigger` / `scripted_effect` 的展开评估器，提供对应的意向动作（单步展开 / 递归展开），交互与边界规则同上
- [ ] P3 实现定义注入（`definition_injection`）的展开评估器，提供对应的意向动作（合并当前 / 合并所有），支持复制文本与打开为临时文件
- [ ] P3/DELAY 参考 Rust 插件的宏展开交互形态完善展开预览 UI（递归 + 单步）：
  - 弹出包含编辑器的 popup（无顶栏，非模态 dialog）；
  - 暂不提供装订线图标；
  - 暂不在预览中启用语义高亮。
