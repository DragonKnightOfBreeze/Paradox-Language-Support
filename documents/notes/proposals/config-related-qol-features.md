# 规则系统关联 QoL 增强特性

> - 模块：后端 > 规则系统
> - 版本：v3.1.x+
> - 状态：待规划（拆分自原 `roadmap.md`）
> - 标签：`CWT` / `QoL` / `快速文档` / `引用解析`

## 概述

围绕 CWT 规则文件与快速文档编写体验的便捷性新功能、扩展选项与引用解析增强。

## 候选任务

- [ ] P3/QoL 支持扩展的规则选项 `## doc = some.md`，通过引用指定的文档路径来包含额外的快速文档文本，并同步补充相关参考文档
- [ ] P3/QoL 支持扩展的规则选项 `## inject_doc`（使用当前规则路径）或 `## inject_doc = some/config.cwt@some/path`，通过引用指定规则文件路径上的指定规则路径来注入额外的快速文档文本，并同步补充相关参考文档
- [ ] P3/QoL 提供对规则文件中的文件路径引用和规则路径引用的引用解析
